# Contributing

Thank you for improving the OWASP Codex Skill.

1. Open an issue for substantial behavior or policy changes.
2. Keep review behavior local-first, evidence-based, and non-destructive.
3. Add only tools with an OSI-approved license; document network behavior, data handling, rule/database licensing, and safe defaults.
4. Never make installation, source upload, remote rules, telemetry, or active scanning implicit.
5. Run `npm test`, `npm run validate`, and the Codex skill validator before submitting a pull request.
